# 功能交付与联调说明

## 启动

需要 Node.js 22 或更新版本。在项目根目录将 `.env.example` 复制为 `.env`，仅在本机 `.env` 填入已重置的微信 AppID 与 AppSecret。后端现在自动读取该文件；修改后需重启。

CMD 中执行：

```
cd /d D:\elaioin
node backend\server.js
```

开发者工具仍使用 `utils/api.js` 中的地址。真机需使用可访问的后端地址；上线需 HTTPS 与 request 合法域名。后端目录、数据、环境文件已排除在小程序打包范围之外。

## 已连接的功能

- 微信快捷登录：勾选协议 → wx.login → 服务端 code2Session → 创建/复用账户 → 应用 token。token 七天有效，可退出注销当前 token；网络暂时失败不删除登录凭证。具体微信错误会显示说明。
- 站内消息：双方先微信登录，在账户设置复制账户编号；消息页输入对方编号即可发送。对方打开消息页后每五秒刷新，支持回复、已读标记、去重和发送频率限制。只有发送人/接收人可访问。不是微信好友聊天、没有订阅通知推送。
- 缴费信息：创建服务端固定 ¥1 商品的演示订单，支持待支付、取消、演示已支付、演示已退款；查询隔离、重复操作幂等、禁止跨账户操作。开发环境可演示，production 环境禁止演示资金操作。
- 我的预约：记录预约意向、查看及取消。当前首页交流者是静态示例，尚未绑定真实交流者，因此不承诺排期、接单或实际提供服务。
- 收藏：添加、查看、取消；昵称与头像沿用已有保存接口。
- 协议可点击阅读，但为演示文本，正式上线前需要运营方补充和确认。

## 明确未开通的功能

| 功能 | 缺少项与当前行为 |
| --- | --- |
| 真实微信登录联调 | 需正确配置新的 AppSecret、AppID 和可访问微信的后端网络；测试没有使用真实微信凭证 |
| 手机号一键登录 | 需在微信后台确认接口资格/权限；默认禁用，确认后设置 WECHAT_PHONE_ENABLED=true。此开关不代表平台已授予权限 |
| 短信验证码 | 需短信服务商及签名模板；未配置时禁止发送，不再返回假验证码。旧短信接口尚未通过真实服务商联调 |
| 真实微信支付/退款 | 当前未实现商户支付适配器。需认证小程序、合格主体、JSAPI/小程序支付权限、商户号绑定、商户私钥/证书、APIv3密钥、HTTPS回调；之后实现签名下单、回调验签解密、查单、对账与真实退款。没有权限时不能真实扣款 |
| 实名认证 | 未接入身份核验与审核后台，接口和页面阻止提交，避免仅存文件名却宣称已认证 |
| 网课/视频/AI/群组 | 缺少内容、运营配置或对应服务商，页面注明未开放。并非全部由微信认证阻塞 |
| 微信订阅通知 | 尚未选择消息模板、实现用户订阅和服务端推送 |
